# A. Công việc đang làm
1. ghi rõ thời gian up file ini, toàn bộ thời gian từ lúc bấm (đếm giờ)
2. đọc file ini bằng thi viện inifile(tham khảo ở đâu, có bao nhiêu loại thư viện cho phép, tại sao lại chọn cái đấy, so sánh đánh giá)
3. kết nối 3 mqtt, đọc dữ liệu từ cảm biến gì đấy
4. cấu hình dữ liệu trong file ini (3 mqtt server bao gồm server,port,username....)
5. thêm 1 vùng littlefs để lưu file ini (vài trăm kB). (hỏi anh Thế Anh để dữ liệu bao nhiêu là hợp lí)
6. gửi dữ liệu đồng thời trên 3 mqtt server và xem có khác gì nhau không, có lỗi không
7. cấu hình đc nhiều wifi, mang về nhà thì nó tự động kết nối, mang đi sửa cũng tự sửa. kết nối từ trên xuống, hoặc kết nối ưu tiên quét cái đã kết nối rồi. code thuật toán tói ưu dò
